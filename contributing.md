# Contribuição

Obrigado por contribuir.

Siga estas diretrizes ao contribuir com esse projeto.

## Código de conduta

Este projeto segue o [código de conduta](code-of-conduct.md) da Adobe. Ao participar,
você concorda em manter este código. Relatar comportamento inaceitável para
[Grp-opensourceoffice@adobe.com](mailto:Grp-opensourceoffice@adobe.com).

## Guia do colaborador

Consulte o [guia do colaborador do Adobe Docs](https://experienceleague.adobe.com/en/docs/contributor/contributor-guide/introduction).

## Fazer uma pergunta

Arquive um problema para fazer uma pergunta. Os responsáveis pelo projeto discutem a direção do projeto
e soluções propostas nos threads de problemas.

## Contrato de licença de colaborador

Todas as contribuições de terceiros exigem um contrato de licença de colaborador (CLA) assinado.
O contrato concede à Adobe permissão para redistribuir suas contribuições como parte
do projeto. [Assine o CLA](https://opensource.adobe.com/cla.html). Você precisa
envie o Adobe CLA apenas uma vez.

## Revisões de código

Enviar alterações como pull requests. Os responsáveis pelo projeto analisam cada solicitação de pull.
Para obter mais informações, consulte [Sobre solicitações de pull](https://help.github.com/pt/articles/about-pull-requests/).

## Tornar-se um confirmador

Os responsáveis têm acesso total à gravação e ajudam a orientar o projeto. Confirmadores existentes
processo de nomeação interna e deve chegar a um consenso lento antes de
convidar um novo confirmador. Entre em contato com um confirmador existente se quiser obter mais informações
envolvidos.

## Problemas de segurança

Não relate problemas de segurança neste rastreador de problemas. Em vez disso, [contate a segurança da Adobe](https://helpx.adobe.com/br/security/alertus.html).
